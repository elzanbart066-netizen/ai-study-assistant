# AI Study Assistant

Студенттерге арналған көптілді (қазақ, орыс, ағылшын) оқу көмекшісі. Сайт жобалық жоспарға сай жасалды:
AI сұрақ-жауап және веб-іздеу, математика мен логика, код көмекшісі, файл құрастыру (DOCX, PDF, PPTX, TXT),
сурет өңдеу, тарих және профиль.

## Мүмкіндіктер

| Бөлім | Не істейді |
| --- | --- |
| Тіркелу / кіру | Аты-жөні, email, құпиясөз (кемінде 8 таңба). Құпиясөз scrypt арқылы хэштеледі. |
| AI сұрақ-жауап | Қысқа түйін, толық түсіндіру, мысал, нақты қолданылған дереккөздер және «Назар аударыңыз» бөлігі. Өзекті сұрақта веб-іздеу автоматты қосылады. |
| Математика және логика | Сызықтық және квадрат теңдеулер, өрнектер, сандық әдіс, логикалық формулалардың ақиқаттық кестесі. Құрылым: берілгені → тәсіл → қадамдар → жауап → тексеру. |
| Код көмекшісі | Python, JavaScript, Java, C++, C#. Код, түсіндірме, үлгі кіріс/шығыс. Код сайтта орындалмайды. |
| Файл құрастыру | DOCX, PDF, PPTX, TXT. Алдын ала көрініс, жүктеу, дереккөздер тізімі. |
| Сурет өңдеу | PNG/JPG/WebP (5 МБ дейін): қию, бұру, айналы, жарық, контраст, қанықтық, ақ-қара, сепия, инверсия, бұлыңғыр, фон, мәтін. Нұсқауды үш тілде жазуға болады. «Шашын қара түске боя», «аспанды қызғылт қыл» сияқты нұсқауда AI (CLIPSeg) суреттің сол бөлігін тауып, тек соны бояйды. Бастапқы сурет сақталып, жылжымалы салыстыру көрсетіледі. |
| Тарих | Мәтін бойынша іздеу, құрал/күн бойынша сүзу, сұрыптау, сақтау, қайта ашу, жою. Тек өз жазбалары көрінеді. |
| Профиль | Аты-жөні, тіл (профильде сақталады), тарихты сақтау баптауы, тілдер бойынша статистика. |

AI көмекшісі студентке артық сұрақ қоймайды: сұрақ екіұшты болса, ең ықтимал түсінікті таңдап, оны бір сөйлеммен айтады да жауап береді.
Сенімсіздік ашық айтылады, сілтеме ойдан жасалмайды.

## Іске қосу

Node.js 20+ керек.

```bash
cd AIStudyAssistant
npm install
cp .env.example .env      # қажет болса ANTHROPIC_API_KEY жазыңыз
npm run dev               # API: http://localhost:3001, сайт: http://localhost:5173
```

Демо аккаунт (memory режимі): `demo@study.kz` / `demo12345` — 30 дайын жазбасы бар.

Өндірістік нұсқа:

```bash
npm run build
SESSION_SECRET=<32+ таңба> npm start   # сайт пен API бір порттан ашылады
```

### Режимдер

- **AI қосулы** (`ANTHROPIC_API_KEY` бар): жауаптарды Claude (`ANTHROPIC_MODEL`, әдепкі `claude-opus-5-5`) береді, веб-іздеу Claude-тың web search құралы арқылы жүреді, дереккөз ретінде тек жауапта нақты сілтеме жасалған беттер көрсетіледі.
- **Офлайн** (кілт жоқ): теңдеу/логика кірістірілген алгоритммен шешіледі, код кірістірілген үлгілерден беріледі, сұраққа жауап Википедияның қысқаша мазмұнынан құралады (сілтеме және CC BY-SA 4.0 лицензиясы көрсетіледі). Мәтіндік есеп пен еркін код үшін AI керек екені түсінікті хабарланады.

### Серверсіз сайт (GitHub Pages)

`static-site/` — сол интерфейс пен сервистердің браузерде толық жұмыс істейтін нұсқасы: сервер, дерекқор және Claude аккаунты керек емес, сілтеме кез келген браузерде (Chrome т.б.) ашылады.

- Кілтсіз тегін жұмыс істейді: есеп, логика, код үлгілері, файл (DOCX/PDF/PPTX/TXT), сурет өңдеу, Википедия бойынша сұрақ-жауап.
- **Кілтсіз AI:** **Профиль → Кілтсіз AI → Қосу және жүктеу** басылса, тегін Qwen3 1.7B моделі (Apache-2.0, WebLLM арқылы) бір рет жүктеліп, браузердің өзінде (WebGPU) жұмыс істейді. Ол кез келген сұраққа жауап береді, Википедия үзінділерін дереккөз ретінде қолданып, сілтемесін көрсетеді. Жаңа Chrome немесе Edge керек; модель шамамен 1–1,5 ГБ, браузер кэшінде сақталады.
- **Суретті AI арқылы бояу:** CLIPSeg моделі (Apache-2.0, transformers.js) бірінші қолданғанда бір рет жүктеледі (~150 МБ) және браузерде жұмыс істейді. Кілт пен сервер керек емес.
- Тегін мықты AI үшін студент **Профиль → Тегін Google Gemini кілті** өрісіне өз кілтін жазады (кілт [aistudio.google.com/apikey](https://aistudio.google.com/apikey) сайтынан тегін алынады). Кілт тек сол браузерде сақталады және тек `generativelanguage.googleapis.com`-ға жіберіледі. Gemini кілті болса, кілтсіз модель мен дайын есептердің орнына жауапты Gemini жазады.
- Толық AI керек болса, студент **Профиль → Claude API кілті** өрісіне өз кілтін жазады. Кілт тек сол браузерде (`localStorage`) сақталады және тек `api.anthropic.com`-ға жіберіледі.
- Деректер браузер жадында тұрады: бетті жаңартқанда тарих тазарады. Ашылғанда демо аккаунтқа өзі кіреді.

```bash
npm run build:static   # static-site/dist — кез келген статикалық хостингке жүктеуге болады
```

`main`-ге push жасалғанда `.github/workflows/study-assistant-pages.yml` сайтты GitHub Pages-ке жариялайды (репозиторийде **Settings → Pages → Source: GitHub Actions** бір рет қосылуы керек). Мекенжайы: `https://<пайдаланушы>.github.io/<репозиторий>/`.

### Деректер қоры

- `DB_DRIVER=memory` — In-Memory репозиторий (прототип, тесттер, демо).
- `DB_DRIVER=mysql` — MySQL 8. Схема (`database/schema.sql`) сервер іске қосылғанда автоматты жасалады.

```bash
npm run db:seed                      # 4 студент, 120 хабарлама, барлығы 250+ жазба
npm run db:backup                    # backups/backup-<уақыт>.json
npm run db:backup -- restore <файл>  # бір транзакциямен қалпына келтіру
```

Кестелер: `users`, `user_settings`, `conversations`, `messages`, `sources`, `generated_assets`, `saved_items` (сыртқы кілттер, email бірегейлігі, utf8mb4).
Жауап пен дереккөздер, хабарламаны жою және файл жазбалары транзакциямен сақталады.

## Архитектура

```
AIStudyAssistant/
├── src/pages/            10 экран: басты бет, кіру/тіркелу, dashboard, AI сұрақ, есеп, код, файл, сурет, тарих, профиль
├── src/components/       Header, Sidebar, LanguageSwitcher, ChatInput, AnswerCard, SourceCard, UploadPanel, Notification, Modal
├── src/services/         auth, assistant, file, image, history API клиенттері; суретті canvas-та өңдеу
├── src/models/           User, Conversation, Message, Source, GeneratedAsset және нәтиже түрлері
├── src/i18n/             қазақ, орыс, ағылшын сөздіктері
├── src/styles/           түстер, орналасу, responsive
├── server/routes/        REST API
├── server/services/      AuthService, AssistantService, SearchService, StudyTools (MathSolver, Logic, CodeTemplates), MediaService, HistoryService
├── server/repositories/  DataStore келісімшарты, MemoryStore, MySqlStore
├── server/integrations/  Claude (Anthropic SDK), Wikipedia іздеу, DOCX/PDF/PPTX/TXT генераторлары
├── database/             схема, демо/тест деректері, backup/restore
└── tests/                модульдік және интеграциялық тесттер
```

Ағын: студент → React интерфейсі → Express API → бизнес-сервис → AI / іздеу / файл генераторы немесе деректер қоры → нәтиже → интерфейс.

## API

| Әдіс | Маршрут | Міндеті |
| --- | --- | --- |
| POST | `/api/auth/register` | Тіркелу |
| POST | `/api/auth/login` | Кіру |
| POST | `/api/auth/logout` | Шығу |
| GET | `/api/auth/me` | Ағымдағы пайдаланушы |
| POST | `/api/assistant/ask` | Сұрақ және веб-іздеу (`prompt`, `webSearch`, `language`) |
| POST | `/api/assistant/solve` | Есеп шығару (`prompt`) |
| POST | `/api/assistant/code` | Код жасау (`prompt`, `codeLanguage`) |
| POST | `/api/files/create` | Файл құрастыру (`title`, `instruction`, `format`) |
| POST | `/api/images/edit` | Өңделген суретті сақтау (`original`, `edited`, `operations`) |
| GET | `/api/assets/{id}` | Файлды/суретті жүктеу (тек иесіне) |
| GET | `/api/history` | Тарих (`q`, `type`, `from`, `to`, `saved`, `sort`, `page`, `limit`) |
| GET | `/api/history/stats` | Статистика |
| GET | `/api/history/{id}` | Жазбаны ашу |
| PUT | `/api/history/{id}/saved` | Сақтау / сақтаудан алу |
| DELETE | `/api/history/{id}` | Өз жазбасын жою |
| GET / PUT | `/api/profile` | Профиль |
| PUT | `/api/profile/language` | Тілді жаңарту |

Қате жауабы: `{ "error": { "code", "reason", "field", "requestId" } }`. Интерфейс кодты таңдалған тілде түсіндіреді және Request ID көрсетеді.

## Қауіпсіздік

- Құпиясөз ашық сақталмайды (scrypt + тұз); сессия — қол қойылған httpOnly cookie.
- SQL сұраныстары параметрленген; әр сұраныста сессия мен ресурстың иесі тексеріледі.
- API кілттері тек серверде; браузерге берілмейді.
- Сурет файлдың нақты қолтаңбасы (PNG/JPG/WebP) және өлшемі бойынша тексеріледі; файл жолдары сақтау қалтасынан шыға алмайды.
- Журналда құпиясөз, кілт, email жазылмайды; әр жазбада уақыт, модуль, request ID, техникалық код бар.
- Бөгде сайттан келген POST/PUT/DELETE сұраныстары қабылданбайды; кіру мен AI сұраныстарына жылдамдық шегі бар.

## Тестілеу

```bash
npm test        # 66 тест: алгоритмдер, валидация, қауіпсіздік, API сценарийлері
npm run build   # TypeScript тексеруі және өндірістік жинақ
```

Интеграциялық тесттер In-Memory деректер қорымен, жалған AI және іздеу провайдерімен жүреді. MySQL репозиторийі сол `DataStore` келісімшартын орындайды; оны нақты MySQL серверінде `npm run db:seed` арқылы тексеріңіз.

## Авторлық құқық және лицензиялар

- Интерфейс, иконкалар, логотип және басты беттегі сурет осы жоба үшін SVG түрінде қолмен салынған; сырттан сурет алынбаған.
- Қаріптер: сайт тек құрылғының жүйелік қаріптерін қолданады. PDF-те қазақ әріптері үшін npm арқылы орнатылатын DejaVu Sans қолданылады (Bitstream Vera лицензиясы, еркін тарату рұқсат етілген); қаріп файлы репозиторийге қосылмаған.
- Кітапханалар: React, React Router, Express, mysql2, docx, PDFKit, PptxGenJS — MIT; Anthropic SDK, WebLLM, Qwen3 моделі, transformers.js, CLIPSeg моделі — Apache-2.0.
- Википедия мәтіні CC BY-SA 4.0 лицензиясымен: жауапта мақала сілтемесі мен лицензия көрсетіледі, тек қысқа үзінді алынады.
- AI-ға кітап, мақала немесе ән мәтінін ұзақ көшірмей, өз сөзімен түсіндіру тапсырылған.
